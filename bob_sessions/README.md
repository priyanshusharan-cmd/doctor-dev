# IBM Bob Session Screenshots

This directory stores screenshots and exported artifacts from IBM Bob IDE task sessions used during Doctor Dev development.

## How to add screenshots

For each significant Bob task session during development:

1. Complete the work in Bob IDE
2. Export or screenshot the task session summary
3. Name the file: `session-NNN-brief-description.png`
4. Add a one-line entry to the table below
